# Round 0 — 诊断 (Diagnostic)

**这是整个计划的起点，不可跳过。** 目的不是打分，是定位：你这一年衰减在哪、哪些其实还很稳。

## 怎么做

1. 打开 `diagnostic-test.md`，**全英文、无计算器、不查笔记**，模拟真实考场。
2. 不用一次做完——分 2–3 次（每次 30–45min）做完整张卷即可（见 schedule）。
3. 每题如果卡住，**写下你卡在哪一步**（这是诊断的核心信息，比答案更重要）。
4. 做完让助教用 `answer-key.md` 批改，并据结果**批量填 `progress/skill-map.md`**：会且快=达标，会但慢/不确定=弱点偏达标，不会/卡步=弱点，完全空白=弱点。

## 设计说明

- 每个模块 4–6 题，覆盖 skill-map 的全部微知识点，便于一一对应定位。
- 含 2 道超纲题（分部积分、部分分式），用来确认 1014 承重墙的起点——**不会很正常**，AB 没教过。
- 不要自己先看 answer-key。
