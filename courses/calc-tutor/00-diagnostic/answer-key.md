# Answer Key（助教用 · 学生先别看）

仅供批改。批改后据此填 skill-map。每题给最终答案 + 关键步骤 + 常见断点。

1. **[1.1]** = 6。因式分解 (x−3)(x+3)/(x−3)→x+3→6。
2. **[1.1]** = 1/4。分子有理化 ×(√(x+4)+2)。断点常在"想不到有理化"。
3. **[1.3]** = 3/2。最高次系数比。
4. **[1.4]** = 5。lim sin(5x)/x = 5·lim sin(5x)/(5x)=5。
5. **[1.2]** a=2（左1=右a+1→a=0? 检查：左极限=1²=1，右极限=a+1，连续需 a+1=1→a=0）。**更正：a=0。** 定理：介值定理 (IVT)，g(1)=−1<0,g(2)=1>0。
6. **[2.1]** f′(x)=−1/x²。用 [1/(x+h)−1/x]/h 通分→−1/(x(x+h))→−1/x²。断点常在通分。
7. **[2.2]** 积法则：(6x)(x³−2x)+(3x²+1)(3x²−2)=15x⁴−15x²−2（展开核对）。
8. **[2.3]** 10(2x+1)⁴。
9. **[2.4]** (a) cos x·eˣ+sin x·eˣ = eˣ(sin x+cos x)。 (b) 2x/(x²+1)。
10. **[2.5]** dy/dx = −x/y。
11. **[3.1]** dV/dt=4πr²·dr/dt → 12=4π·9·dr/dt → dr/dt=1/(3π) cm/s。
12. **[3.2]** 5×5 正方形，面积 25。
13. **[3.3]** MVT：f 在[a,b]连续、(a,b)可导，则存在 c 使 f′(c)=(f(b)−f(a))/(b−a)。此处 (16−0)/4=4=2c→c=2。
14. **[3.4]** f′=3x²−3=0→x=±1。增:(−∞,−1)∪(1,∞)，减:(−1,1)。局部极大 x=−1(值2)，极小 x=1(值−2)。拐点 x=0。
15. **[3.5]** = 1/2。两次洛必达或泰勒。
16. **[4.1]** x⁴ − 3x² + 5x + C。
17. **[4.4]** (x²+1)⁵/5 + C（u=x²+1）。
18. **[4.3]** ∫₀²(3x²+2)dx=[x³+2x]₀²=8+4=12。 d/dx∫ₐˣf(t)dt = f(x)（FTC 第一部分）。
19. **[4.5]** 交点 x=0,2。∫₀²(2x−x²)dx=[x²−x³/3]₀²=4−8/3=4/3。
20. **[4.2]** Δx=1/2，右端点 0.5,1,1.5,2 → (1/2)(0.25+1+2.25+4)=(1/2)(7.5)=15/4。
21. **[4.6]** 分部积分 u=x,dv=eˣdx → x·eˣ − eˣ + C。**没学过很正常。**
22. **[4.7]** 2/(x+1) + 1/(x+2)。（3x+5=A(x+2)+B(x+1)→A=2,B=1）**没学过很正常。**

## 批改后填 skill-map 的判定

- 做对且快 → 达标（计算类若无计算器仍快、稳 → 可直接精通）
- 做对但慢/犹豫/查了脑中模糊规则 → 弱点偏达标，标弱点优先复习
- 做错或卡步 → 弱点
- 21/22 空白或卡 → 弱点（预期内，Round1 的 04 模块会补）
