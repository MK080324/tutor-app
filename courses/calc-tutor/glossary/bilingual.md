# 中英概念对照表 (Bilingual Glossary)

> 每引入/复习一个术语就登记一行。格式：英文 — 中文 — 一句话定义/触发记忆。
> 这是为了消灭"英文符号 ↔ 中文概念"的检索断层（学生当年全英文学）。

## 极限与连续

| English | 中文 | 一句话 |
|---|---|---|
| limit | 极限 | x 趋近某值时函数的趋势值 |
| continuity | 连续性 | 极限值 = 函数值，图像不断 |
| Intermediate Value Theorem (IVT) | 介值定理 | 连续函数在区间内取遍两端点之间所有值 |
| Squeeze Theorem | 夹逼定理 | 被两个同极限函数夹住，自己也收敛到该极限 |
| asymptote | 渐近线 | 曲线无限趋近但不相交的直线 |

## 导数

| English | 中文 | 一句话 |
|---|---|---|
| derivative | 导数 | 瞬时变化率 / 切线斜率 |
| chain rule | 链式法则 | 复合函数求导：外导×内导 |
| implicit differentiation | 隐函数求导 | 方程两边对 x 求导，把 y 当 x 的函数 |
| Mean Value Theorem (MVT) | 中值定理 | 区间内必有一点切线斜率=平均变化率 |
| L'Hôpital's rule | 洛必达法则 | 0/0 或 ∞/∞ 时分子分母分别求导再取极限 |

## 积分

| English | 中文 | 一句话 |
|---|---|---|
| antiderivative | 反导数/原函数 | 求导能还原成原函数的那个函数 |
| definite integral | 定积分 | 区间上的累积量 / 带符号面积 |
| Fundamental Theorem of Calculus (FTC) | 微积分基本定理 | 把求导与积分联结起来的定理 |
| u-substitution | 换元积分 | 用换元把复合结构的积分化简 |
| integration by parts | 分部积分 | ∫u dv = uv − ∫v du（AB 未教，为 1014 准备） |
