# Round 2 — 考试级升级（A 级 / 精通）

目标：skill-map 核心项到「精通」（**无计算器、限时**下含难题正确率 ≥ 85%，且能写 justify）。

这是同一批内容的**加压档**，不是新内容。三条主线：

1. **无计算器速度训练**：手算三角值/对数/繁分式/因式分解。港科考场全程禁计算器，这是 AB 没逼过你的地方。每次 session 用 5–10min 做无计算器速算热身。
2. **港科难度难题**：多步骤、代数重、脚手架少。来源：教材 (Briggs/Stewart) 章末难题、MIT 18.01 problem sets。
3. **限时套题 + 考试技巧**：定时做小套题，练时间分配、书写规范、justify 写法（IVT/MVT/FTC 要写清依据）。

按模块逐个加压，状态从「达标」抬到「精通」时更新 skill-map。
