# Round 3 — 水平检测（整卷）

目标：用完整卷子在**无计算器、限时**条件下检测真实水平，复盘漏洞回灌 skill-map。

## 卷源（现实排序——1013 真题公开极少，不做假承诺）

1. **AP Cal AB 官方 released exams / FRQ**（免费、量大、最权威）——主力。College Board 官网有历年 free-response。
2. **MIT 18.01 期中期末**（免费、无计算器、比 1013 更硬，适合检测上限）——MIT OCW。
3. **教材章末综合测验**（Briggs/Cochran/Gillett 或 Stewart 第 9 版的 chapter review / practice exam）。
4. **HKUST MATH1013 真题**：closed exam，公开少；若能从学长/图书馆拿到就用，**拿不到不强求**。

## 流程（每套 ≈ 1 单元 + 复盘）

1. 限时、无计算器、模拟考场做完整套。
2. 助教批改，按错题定位到 skill-map 的微知识点，**把退步的项打回「弱点」**。
3. 针对漏洞做一两次定向补强，再换下一套。
4. 目标：连续 2 套达到 A 级阈值（≥ 85%、justify 完整）即视为达标。

可延续进开学头两周，与 1013 课程并行。
