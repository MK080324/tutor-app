# 物理化学私教（HFI 集训预备）

在 **Claude Code 终端里直接上课**。这是给弟弟提前学完人教版 9 年级物理 + 化学、为 HFI 集训营和分班考打底的一套自带进度记忆的私教系统。

## 怎么上课

1. 在这个文件夹（`phys-chem-tutor/`）里打开 Claude Code。
2. 直接说「上课」「上物理」「上化学」或「继续」。
3. 老师（Claude）会自动读取进度，接着上次的地方往下教。

每次新开对话不用交代历史——所有进度都存在文件里，老师会自己读。

## 目标

- **达标**：达到人教版《阳光学业评价》的难度水平（这是难度标尺，题由老师现出，不需要原书）。
- **跟上 8 月初的物理化学集训营**：对 9 年级（部分高一）知识"知道是什么、会用基本公式"。
- **破壁**：每个概念中英对照，逐步习惯英文术语和英文题，为入学后中英双语教学做准备。

## 计划

- 物理 21 课 + 化学 21 课 ≈ 42 课时；现在到 8 月初每周 5-6 次课。
- 物理：热学 → 电学（重头）→ 电磁 →（高一力学选讲）
- 化学：走进化学 → 微观构成 → 化学式方程式（地基）→ 碳与燃料 → 金属溶液酸碱盐 →（初高衔接选讲）

## 给弟弟的三个提醒

1. **公式都是纯文本**：终端里不会显示漂亮的数学排版，`v = s / t` 就是速度公式，习惯就好。
2. **要看图时**：老师会生成一个 `.html` 文件，按它给的路径用浏览器打开看。
3. **看不懂随时贴回来**：课本、试卷、别处看到不懂的，直接复制文字粘到终端问老师。

## 给家长

- 题目老师自己出（难度参照《阳光学业评价》），**不需要准备任何教辅原书**。
- 想换/补教材，或有想让老师对着讲的试卷/错题：放进对应科目的 `materials/`，老师下次上课会读取并据此调整。这是可选的。
- 想看学了多少：直接看 `physics/progress.md`、`chemistry/progress.md` 的表格。
