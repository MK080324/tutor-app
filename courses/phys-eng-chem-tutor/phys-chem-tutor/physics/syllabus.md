# 物理教学大纲（HFI 集训预备）

覆盖人教版九年级全一册（热学、电学、电磁学）核心达标内容，尾部接 3 节高一力学选讲做初高衔接。
每节约 60min，对标《阳光学业评价》。**关键路径（不可打乱顺序）：电路 → 电流电压电阻 → 欧姆定律 → 电功率**。

公式一律写成纯文本单行（终端可读），禁用 LaTeX。每节列出本节"破壁术语"——必须中英对照讲并写入 term-bank.md。

## P0-热学（内能）：Lesson 1-4

### Lesson 1：分子热运动
- 知识点：物质由分子原子构成；扩散现象；分子永不停息地做无规则运动；分子间的引力和斥力
- 教学目标：理解分子动理论三要点，能用扩散解释生活现象
- 破壁术语：分子(Molecule)、原子(Atom)、扩散(Diffusion)
- 对标：内能·第13章第1节
- 前置：无

### Lesson 2：内能与改变内能的方式
- 知识点：内能概念（分子动能+分子势能）；温度与内能的关系；改变内能的两种方式——做功、热传递；热量
- 教学目标：区分温度/内能/热量三个概念，知道两种改变内能的方式
- 破壁术语：内能(Internal energy)、温度(Temperature)、热量(Heat)、做功(Doing work)、热传递(Heat transfer)
- 对标：内能·第13章第2节
- 前置：L1

### Lesson 3：比热容与热量计算
- 知识点：比热容概念；水的比热容大及其意义；热量计算 `Q = c * m * (t - t0)`（吸热放热）
- 教学目标：理解比热容，熟练用 Q=cmΔt 计算吸放热
- 破壁术语：比热容(Specific heat capacity)、焦耳(Joule)
- 对标：内能·第13章第3节
- 前置：L2

### Lesson 4：内能的利用·热机与热值
- 知识点：热值 `Q = m * q`；燃料燃烧放热；热机（汽油机/柴油机四冲程）；热机效率 `效率 = W有用 / Q总`；能量守恒
- 教学目标：会算燃料放热和热机效率，理解能量转化与守恒
- 破壁术语：热值(Calorific value)、热机(Heat engine)、效率(Efficiency)、能量守恒(Conservation of energy)
- 对标：内能的利用·第14章
- 前置：L3

## P0-电学：Lesson 5-14（考试重头，最重要）

### Lesson 5：电荷·电流·电路
- 知识点：两种电荷（正负）及相互作用；摩擦起电；电流的形成与方向（正电荷定向移动方向）；电路三部分（电源/用电器/导线+开关）；电路图与元件符号；通路/断路/短路
- 教学目标：会看会画简单电路图，理解电流方向
- 破壁术语：电荷(Charge)、电流(Current)、电路(Circuit)、电源(Power source)、开关(Switch)
- 对标：电流和电路·第15章
- 前置：无（电学起点）

### Lesson 6：串联电路与并联电路
- 知识点：串联/并联的特征与识别；连接实物图与电路图互画；干路与支路
- 教学目标：能判断、连接、画出串并联电路
- 破壁术语：串联(Series)、并联(Parallel)
- 对标：第15章·串并联
- 前置：L5
- 备注：此处可能需 HTML 画电路图

### Lesson 7：电流与电流表
- 知识点：电流单位安培 A；串联电流处处相等、并联干路=各支路之和；电流表的使用（串联接入、量程、正负接线柱、不能直接接电源）
- 教学目标：会读会接电流表，掌握串并联电流规律
- 破壁术语：电流表(Ammeter)、安培(Ampere)
- 对标：第15章·电流的测量
- 前置：L6

### Lesson 8：电压与电压表
- 知识点：电压单位伏特 V；电源电压；串联电压=各部分之和、并联各支路电压相等；电压表的使用（并联接入、量程、正负接线柱）
- 教学目标：会读会接电压表，掌握串并联电压规律；分清电流表/电压表接法
- 破壁术语：电压(Voltage)、伏特(Volt)、电压表(Voltmeter)
- 对标：电压·电阻·第16章前半
- 前置：L7

### Lesson 9：电阻与变阻器
- 知识点：电阻概念与单位欧姆 Ω；影响电阻的因素（材料/长度/横截面积/温度）；定值电阻；滑动变阻器的构造、原理、接法（一上一下）
- 教学目标：理解电阻，会用滑动变阻器改变电流
- 破壁术语：电阻(Resistance)、欧姆(Ohm)、变阻器(Rheostat / Variable resistor)
- 对标：电压·电阻·第16章后半
- 前置：L8

### Lesson 10：欧姆定律
- 知识点：探究电流与电压、电阻的关系（控制变量法）；欧姆定律 `I = U / R`；变形 `U = I * R`、`R = U / I`
- 教学目标：理解并熟练运用欧姆定律做基本计算
- 破壁术语：欧姆定律(Ohm's law)、控制变量法(Control of variables)
- 对标：欧姆定律·第17章前半
- 前置：L9

### Lesson 11：欧姆定律的应用·伏安法测电阻
- 知识点：串联电路欧姆定律（电流相同，电压电阻成正比）；并联电路欧姆定律（电压相同）；伏安法测电阻 `R = U / I`（电路连接、多次测量取平均）
- 教学目标：会在串并联中用欧姆定律，会设计伏安法测电阻实验
- 破壁术语：伏安法(Volt-ammeter method)
- 对标：欧姆定律·第17章后半
- 前置：L10

### Lesson 12：电能·电功·电功率
- 知识点：电能与电能表（千瓦时 kWh）；电功 `W = U * I * t`；电功率 `P = W / t = U * I`；千瓦特 kW
- 教学目标：理解电功与电功率的区别，会算电费、会用 P=UI
- 破壁术语：电能(Electrical energy)、电功(Electrical work)、电功率(Electrical power)、瓦特(Watt)
- 对标：电功率·第18章前半
- 前置：L11

### Lesson 13：电功率综合·额定功率·测小灯泡功率
- 知识点：额定电压/额定功率与实际功率；纯电阻电路 `P = U*I = I^2 * R = U^2 / R`；伏安法测小灯泡电功率
- 教学目标：会用三个功率公式选择计算，理解额定与实际的区别
- 破壁术语：额定功率(Rated power)、实际功率(Actual power)
- 对标：电功率·第18章后半
- 前置：L12

### Lesson 14：焦耳定律·安全用电·家庭电路
- 知识点：电流的热效应；焦耳定律 `Q = I^2 * R * t`；家庭电路（火线零线、保险丝/空气开关、三孔插座接地）；触电与安全用电
- 教学目标：会用焦耳定律算电热，理解家庭电路与安全用电常识
- 破壁术语：焦耳定律(Joule's law)、火线(Live wire)、零线(Neutral wire)、保险丝(Fuse)
- 对标：电功率·第18章 + 生活用电·第19章
- 前置：L13

## P1-电与磁·信息：Lesson 15-18

### Lesson 15：磁现象·磁场·电生磁
- 知识点：磁体/磁极（同名相斥异名相吸）；磁场与磁感线；地磁场；奥斯特实验（电流的磁效应）；通电螺线管的磁场与安培定则（右手定则）
- 教学目标：理解磁场，会用右手定则判断螺线管磁极
- 破壁术语：磁场(Magnetic field)、磁极(Magnetic pole)、磁感线(Magnetic field line)
- 对标：电与磁·第20章前半
- 前置：L5（电流概念）

### Lesson 16：电磁铁·电磁继电器·电动机
- 知识点：电磁铁及其磁性强弱的影响因素；电磁继电器原理；磁场对通电导线的作用力；直流电动机原理（能量转化：电能→机械能）
- 教学目标：理解电磁铁应用与电动机工作原理
- 破壁术语：电磁铁(Electromagnet)、电动机(Electric motor)
- 对标：电与磁·第20章中段
- 前置：L15

### Lesson 17：电磁感应·发电机
- 知识点：电磁感应现象（磁生电）；产生感应电流的条件；发电机原理（机械能→电能）；交流电与直流电
- 教学目标：理解电磁感应，区分电动机与发电机的能量转化
- 破壁术语：电磁感应(Electromagnetic induction)、感应电流(Induced current)、发电机(Generator)
- 对标：电与磁·第20章后半
- 前置：L16

### Lesson 18：信息的传递与能源（达标速览）
- 知识点：电磁波及其传播、波速波长频率关系 `c = λ * f`（了解）；能源分类（可再生/不可再生）；核能、太阳能（了解）；能量转化与守恒回顾
- 教学目标：知道电磁波和能源的基本概念，达标即可，不深究
- 破壁术语：电磁波(Electromagnetic wave)、能源(Energy source)
- 对标：信息的传递·第21章 + 能源·第22章
- 前置：L17

## P2-高一力学选讲（初高衔接）：Lesson 19-21

> 这 3 节为集训"知道是什么"做铺垫，重在概念和图像，不堆难题。先快速复习八年级力学基础，再引入高一新概念。

### Lesson 19：运动的描述·匀速与匀变速直线运动
- 知识点：参考系；速度 `v = s / t`（复习）；加速度 `a = (v - v0) / t`（新）；匀速与匀变速直线运动；s-t 图像与 v-t 图像的读图
- 教学目标：理解加速度概念，会读 s-t / v-t 图像
- 破壁术语：速度(Velocity)、加速度(Acceleration)、参考系(Reference frame)
- 对标：高一·运动的描述（人教必修一）
- 前置：八年级运动学基础

### Lesson 20：力·三种常见力·力的合成
- 知识点：力的概念与三要素；重力 `G = m * g`、弹力、摩擦力（复习八年级）；力的示意图与受力分析入门；同一直线上二力的合成、二力平衡
- 教学目标：会做简单受力分析，会算同向/反向力的合力
- 破壁术语：力(Force)、重力(Gravity)、摩擦力(Friction)、合力(Resultant force)
- 对标：高一·相互作用（人教必修一）
- 前置：L19；八年级力的基础
- 备注：受力分析可能需 HTML 画图

### Lesson 21：牛顿运动定律入门
- 知识点：牛顿第一定律（惯性）；牛顿第二定律 `F = m * a`（核心，会代数计算）；牛顿第三定律（作用力与反作用力）
- 教学目标：理解三大定律，会用 F=ma 做基础计算，理解惯性
- 破壁术语：惯性(Inertia)、牛顿第二定律(Newton's second law)
- 对标：高一·牛顿运动定律（人教必修一）
- 前置：L20
