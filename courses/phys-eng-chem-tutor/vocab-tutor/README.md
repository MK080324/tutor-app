# 背单词私教系统（vocab-tutor）

弟弟英语「提升计划」里**词汇**那条的执行系统。口语/流利度走 Cambly，这里只管背单词。

## 怎么用

1. 在本文件夹 `vocab-tutor/` 里打开 Claude Code 终端。
2. 跟它说「**背单词**」。
3. 它会:读进度 → 取今天的词(到期复习 + 新词) → 现写例句 → 生成一副翻卡 `cards/<日期>.html`。
4. 你/弟弟用**浏览器打开那个 HTML**翻卡:
   - 点卡片 / 空格 = 翻正反面（单词 ↔ 中文+例句）
   - ← → 或左右滑 = 换词
   - 🔊 = 听发音
5. 翻完在终端做个小自测，告诉它哪些没记住 → 它更新 SRS 进度。

## 设计（为什么这么做）

- **词库 `word-bank.md` 只存 词+词性+中文** → 能塞很多词（现有 159 个，还能加）。
- **例句和翻卡 HTML 由 LLM 每天现写** → 语境每次不同、记得更牢，不靠死模板。
- **间隔重复（SRS）由 LLM 读写 `progress.md`** → 没记住的高频再现，记住的逐渐拉长。
- **HTML 是纯翻卡器**（哑视图），不掺逻辑。

## 加生词

读书 / 看视频 / Cambly 碰到不会的词，直接在终端说「加词 obstacle」或把句子贴进来，它会查义、加进词库、排进最近复习。

## 文件

| 文件 | 作用 |
|---|---|
| `CLAUDE.md` | 系统指令（给 LLM） |
| `word-bank.md` | 词库（159 词 + 自加） |
| `progress.md` | SRS 状态 + 统计 + 日志 |
| `template.html` | 翻卡模板（每天复制它） |
| `cards/` | 每天生成的牌组 HTML |
